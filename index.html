進入巡檢測試區

核心 AI 辨識能力與圖例說明

專注於靜態道路標線硬體檢測與駕駛人視覺幾何分析

01. 斑馬線目標偵測

採用 Ultralytics YOLO26n 輕量化架構，自動定位街景影像中的行人穿越道（crosswalk）邊界框並輸出信心度。

02. 標線像素狀態分析

直接截取原圖偵測區域進行灰階直方圖對比與亮度統計，量化標線白漆磨損褪色與環境光線能見度。

03. 駕駛視角空間評估

依據邊界框與畫面邊緣的相對幾何比例，評估視線盲區距離、空間壓迫感及影像裁切完整性。

04. 風險分級巡檢報告

自動彙整五項硬體指標總分（0~7 分），產出低、中、高風險等級與對應養護或駕駛警示建議。

畫面標註圖例： 綠色外框（#00FF00）：偵測到的斑馬線區域 🏷️ 標籤「crosswalk XX%」：模型對該區域為斑馬線的信心程度（信心 < 40% 已自動過濾）

道路硬體危險度評估標準（預設值）

當畫面中有多條斑馬線時，系統自動鎖定「信心度最高」的一條進行下列五項指標評分（滿分 7 分，門檻為教學示範用暫定值）

評估指標 計算方式 0 分（正常） 1 分（注意） 2 分（異常）
1. 標線清晰度（0~2 分） 框內灰階第 90 百分位 − 第 10 百分位（256 格直方圖） 對比度 ≥ 80（預設） 50 ≤ 對比度 < 80 對比度 < 50
2. 框內能見度（0~2 分） 框內灰階像素平均值（0.299R + 0.587G + 0.114B） 70 ≤ 平均亮度 ≤ 200 40~70 或 200~230 < 40（過暗）或 > 230（過曝）
3. 完整度（0~1 分） 框的左、右、上、下任一側距影像邊緣 < 影像對應尺寸 2% 四邊皆保留 ≥ 2% 安全邊距 任一側貼近影像邊緣（< 2%） —
4. 視線盲區（0~1 分，限駕駛視角） 底邊距離比例 = (圖高 − (y + h)) / 圖高 底邊距離比例 ≥ 0.18（預設） 底邊距離比例 < 0.18（預設） —
5. 空間壓迫（0~1 分，限駕駛視角） 高度佔比 = h / 圖高 高度佔比 ≤ 0.25（預設） 高度佔比 > 0.25（預設） —
低風險：總分 ≤ 1 分 中風險：總分 2 ~ 3 分 高風險：總分 ≥ 4 分 無法評估：未偵測到斑馬線

風險類別 辨識場景描述 偵測方式與系統判讀結果
標線褪色或磨損 長期車輪輾壓導致白漆剝落、與柏油路面色差不明顯 透過灰階 P90−P10 對比度下降偵測，判讀為標線清晰度扣分（1~2 分），建議重新刨鋪繪製
光線過暗或過曝 夜間照明不足、隧道口眩光或正午強光直射水面反光 計算框內平均灰階亮度落於 <70 或 >200 區間，判讀為能見度風險（1~2 分），建議改善路燈或重拍
斑馬線被切掉或遮住 鏡頭角度偏斜、大型車輛遮擋或斑馬線延伸出畫面邊界 偵測框邊界貼近影像四邊 2% 內，完整度計 1 分並標示貼邊方位，提醒調整鏡頭或排除遮蔽
視線盲區 車輛已極度逼近停止線或斑馬線，車頭前方存在視覺死角 底邊距離比例小於 0.18，計 1 分（限駕駛視角），提示減速慢行並注意車頭近端死角
空間壓迫 斑馬線在畫面中垂直佔比過大，反應緩衝距離嚴重不足 框高佔圖高比例大於 0.25，計 1 分（限駕駛視角），提示提前減速預留煞車距離
綜合分級 多重硬體缺失同時發生（例如：夜間照明差且標線嚴重磨損） 累加五項指標總分（0~7 分），達 4 分以上歸類為「高風險」並優先列入養護派工清單
未偵測到斑馬線 標線幾乎完全磨滅、嚴重積水覆蓋，或拍攝角度未涵蓋路口 模型無信心 ≥0.4 之輸出，顯示「無法評估（灰）」，建議確認現場標線狀態或更換清晰正面照片

系統能力邊界與尚未支援項目說明

本模型為單一類別（crosswalk）靜態標線偵測模型，不包含動態交通參與者與執法行為判讀

  • 🚫 紅綠燈號誌位置與燈號顏色（紅／黃／綠燈）判讀
  • 🚫 行人、汽機車、自行車等動態目標偵測與軌跡追蹤
  • 🚫 車輛未禮讓行人（路口停讓違規）自動舉發
  • 🚫 紅黃線違規停車或併排停車偵測
  • 🚫 機車騎士未戴安全帽等交通行為類違規

※ 上述功能需額外擴充資料集標註類別、重新訓練多類別物件偵測模型並結合時序追蹤邏輯方可實現。

系統建置架構與核心技術特色

從資料標註訓練到純瀏覽器地端推理的完整技術鏈路

STEP 04｜前端推論
ONNX Runtime Web

瀏覽器直接載入模型執行前處理、推論、NMS 與像素評分。

工程師參數提示：本網頁所有評分門檻與信心度設定皆集中定義於程式碼最上方的 CONFIG 常數區，巡檢單位可依實際鏡頭焦距與養護規範直接調整。

🔒 純地端推論（隱私零外流）

所有影像解碼與神經網路運算皆在使用者裝置瀏覽器記憶體完成，街景照片完全不會上傳至任何外部伺服器。

📐 YOLO 空間比例標定

採用等比例 Letterbox 縮放與精準座標還原演算法，避免畫面拉伸變形影響標線幾何比例判讀。
